# ts06-go-chi-react

Reference project for [gherkin-ai](https://github.com/FennerEduardo/gherkin-ai-cli) 3.0.0. An idempotent saga in Go with the chi router, and a React 19 frontend.

Everything in `generated-specs/` was generated by `ghk generate` from the specification in `features/go_chi_saga.feature`. The project builds, and its generated tests and runtime integration suite pass, as verified on 2026-10-06 (see [Verification](#verification)).

## Stack

| Part | Technology |
|---|---|
| Backend | Go 1.22 (chi) |
| Frontend | React 19 (Redux Toolkit, Vite) |

## Build and test

The commands below are the ones gherkin-ai uses to verify this stack. Run them in `generated-specs` with the toolchain installed, or inside the official image `golang:1.22`.

```bash
cd generated-specs
go mod tidy
go vet ./...
go vet -tags integration ./internal/runtime/...
go build ./...
go test ./...
```

Runtime integration suite (IT1–IT7: transactional outbox, idempotency under concurrency, exactly-once relay, tenant isolation, saga compensation, inbox deduplication and dead-lettering, trace propagation):

```bash
docker run -d --name ghk-pg -e POSTGRES_PASSWORD=ghk -p 5432:5432 postgres:17-alpine
docker run -d --name ghk-mq -e RABBITMQ_DEFAULT_USER=ghk -e RABBITMQ_DEFAULT_PASS=ghk -p 5672:5672 rabbitmq:4-alpine
export DATABASE_URL=postgres://postgres:ghk@localhost:5432/postgres AMQP_URL=amqp://ghk:ghk@localhost:5672
go test -tags integration -count=1 -v ./internal/runtime/...
```

Frontend (`generated-specs/frontend`, image `node:24-bookworm`):

```bash
cd generated-specs/frontend
npm install --no-audit --no-fund --loglevel=error
npm run build
npm test
```
